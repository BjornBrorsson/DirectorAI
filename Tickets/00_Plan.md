# DirectorCut-AI — Board Plan

This board tracks features, bugs, and technical debt for DirectorCut-AI.

## Column Conventions
- **Backlog/**: Planned work. Use `Ready/` for fully specified tickets and `Needs further specification/` for drafts.
- **Ongoing/**: Actively being worked on (one assignee per ticket).
- **Assistance Required/**: Needs human input, credentials, or a decision.
- **Blocked/**: Waiting on a dependency or external issue.
- **Completed/**: Verified done — all acceptance criteria checked off.

## Workflow
See `config.md` for assignees and agent dispatch commands. Tickets use the standard
metadata-table format (Status / Assignee / Priority / Acceptance Criteria / Work Log).

Related workspace conventions: scratch work for a feature lives in `tasks/<feature>/`
(see `.windsurfrules`); durable docs go in `docs/wiki/`.
