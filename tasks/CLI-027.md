> **Status:** Done

## Description

Add user-friendly progress reporting and a `--dry-run` mode that estimates tokens/cost without calling APIs.

## Acceptance Criteria

- [ ] Rich or simple progress output per stage (files processed, tokens estimated, API calls).
- [ ] `--dry-run` walks the pipeline without sending Gemini requests or writing final output.
- [ ] Dry-run report includes: expected tokens per chunk, estimated API cost, proxy sizes, output timeline duration.
- [ ] Progress works in non-TTY mode (plain text fallback).
- [ ] Unit tests verify dry-run produces a report and no API calls.
