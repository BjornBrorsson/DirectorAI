# FCP-023: Timecode & frame-duration math

> **Status:** Done  
> **Phase:** Conformer  
> **Priority:** High  
> **Created:** 2026-08-17  
> **Owner:** TBD

## Description

Convert blueprint timecodes (`HH:MM:SS.mmm`) into FCPXML rational time values for the target frame rate.

## Acceptance Criteria

- [ ] `src/directorcut/conformer/timecode.py` module.
- [ ] Parses `HH:MM:SS.mmm` and `seconds` formats.
- [ ] Outputs FCPXML strings like `442800/6000s` and `100/6000s`.
- [ ] Supports configurable target fps (default 60.0).
- [ ] Rounds consistently and documents rounding behavior.
- [ ] Unit tests for common durations, 23.976/30/60 fps, and midnight rollover.

## Dependencies

- FCP-022

## Notes / Scratch

Use Python's `fractions.Fraction` to avoid floating-point drift. Store times as rationals internally.
