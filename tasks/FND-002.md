## Description

Create a clean, modern Python project layout with dependency management, linting, formatting, and a test runner.

## Acceptance Criteria

- [ ] `pyproject.toml` with project metadata, Python >=3.11, and dev deps (pytest, ruff, mypy or pyright).
- [ ] `src/directorcut/` package directory.
- [ ] `tests/` directory with sample pytest layout.
- [ ] `.env.example` with placeholder keys.
- [ ] `.gitignore` for Python, `.env`, media, and temp files.
- [ ] `README.md` with install and quick-run instructions.
- [ ] `pytest` and `ruff check` pass on an empty tree.

## Notes / Scratch

Prefer `uv` or `pip`+`venv`. Pin dev dependencies to stable versions at least 7 days old.
