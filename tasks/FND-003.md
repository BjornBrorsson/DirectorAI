## Description

Build a cross-platform helper that locates FFmpeg and FFprobe, validates versions, and runs a health check.

## Acceptance Criteria

- [ ] `src/directorcut/ffmpeg.py` module with `find_ffmpeg()`, `find_ffprobe()`, `version()`.
- [ ] Works on Windows (common install paths + PATH) and Linux/macOS (PATH / Homebrew).
- [ ] Raises a clear error if binaries are missing or too old.
- [ ] Unit test stubs a fake binary path and asserts version parsing.
- [ ] Logs discovery attempts and final binary paths.
