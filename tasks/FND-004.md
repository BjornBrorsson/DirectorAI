## Description

Create a typed settings layer that loads secrets from environment variables and supports dev/test/prod modes.

## Acceptance Criteria

- [ ] `src/directorcut/config.py` using Pydantic `BaseSettings` or `Settings`.
- [ ] Required fields: `GEMINI_API_KEY`, `GEMINI_MODEL`, `FFMPEG_PATH`, `FFPROBE_PATH`, `INGEST_DIR`, `OUTPUT_DIR`.
- [ ] `.env.example` documents every variable.
- [ ] Dev mode disables real API calls by default or routes to a test fixture.
- [ ] Unit tests validate missing-key behavior and default overrides.
