# NAR-011: Transcript-to-timestamp mapping

> **Status:** Done  
> **Phase:** Pass 1  
> **Priority:** High  
> **Created:** 2026-08-17  
> **Owner:** TBD

## Description

Generate a spoken-line array mapped to real timestamps. Can use Gemini audio understanding or an external Whisper step.

## Acceptance Criteria

- [ ] `src/directorcut/narrative/transcript.py` module.
- [ ] Produces objects: `time_start`, `time_end`, `spoken_text`.
- [ ] If a script is provided, align script lines to audio using word-level timing (or sentence-level fallback).
- [ ] If no script, transcribe directly and return segments.
- [ ] Handles overlapping/noisy audio gracefully with confidence logging.
- [ ] Unit tests with synthetic audio segments or mocked API responses.

## Dependencies

- NAR-010, FND-004

## Notes / Scratch

Gemini 3.7 Flash can process audio natively; decide whether to use that exclusively or add Whisper fallback. Start with Gemini to keep cloud surface small.
