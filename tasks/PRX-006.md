# PRX-006: Ingestion engine

> **Status:** Done  
> **Phase:** Proxy Engine  
> **Priority:** High  
> **Created:** 2026-08-17  
> **Owner:** TBD

## Description

Scan the `/ingest` directory, validate required inputs, and produce a run manifest for the pipeline.

## Acceptance Criteria

- [ ] `src/directorcut/ingest.py` module.
- [ ] Detects gameplay video file(s), voiceover audio, and optional script `.txt`.
- [ ] Validates that files exist, are non-empty, and have supported extensions.
- [ ] Produces an `IngestManifest` dataclass/Pydantic model with paths and detected frame rate/duration via FFprobe.
- [ ] Returns a clear error report if inputs are missing.
- [ ] Unit tests with a temporary ingest folder.

## Dependencies

- FND-003, FND-004

## Notes / Scratch

Support `.mp4`, `.mov`, `.mkv` for video; `.mp3`, `.wav`, `.m4a` for audio; `.txt` for script.
