> **Status:** Done  
> **Phase:** Safety  
> **Priority:** High  
> **Created:** 2026-08-17

## Description

Ensure every Gemini call uses a strict JSON schema and that parse failures are caught and logged.

## Acceptance Criteria

- [ ] `src/directorcut/gemini_client.py` centralizes all Gemini API calls.
- [ ] Every call includes `response_schema` (or equivalent structured-generation config).
- [ ] Response is validated against the relevant Pydantic model before returning.
- [ ] On validation failure, log raw response snippet and raise a domain exception.
- [ ] Retry with exponential backoff on transient API errors (configurable).
- [ ] Unit tests mock malformed JSON, missing fields, and rate-limit responses.
