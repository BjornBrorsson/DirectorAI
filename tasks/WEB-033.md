# WEB-033: Backend API service

> **Status:** Done  
> **Phase:** Web Frontend  
> **Priority:** High  
> **Created:** 2026-08-17  
> **Owner:** TBD

## Description

Create a lightweight backend API (e.g., FastAPI) that exposes the CLI pipeline over HTTP/WebSocket for the web UI.

## Acceptance Criteria

- [ ] `src/directorcut/api/` module with FastAPI app.
- [ ] Endpoints: `POST /projects`, `GET /projects`, `POST /projects/{id}/run`, `GET /projects/{id}/status`, `GET /projects/{id}/download`.
- [ ] WebSocket or SSE endpoint for live pipeline progress.
- [ ] Serves built frontend from `frontend/dist/` in production mode.
- [ ] Unit/integration tests with `TestClient`.
- [ ] API routes use existing stage modules; no duplicated business logic.

## Dependencies

- CLI-026, FND-004

## Notes / Scratch

Keep the API stateless where possible; store project metadata and run manifests on disk under `output/projects/`.
