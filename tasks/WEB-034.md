# WEB-034: Project upload / ingest UI

> **Status:** Done  
> **Phase:** Web Frontend  
> **Priority:** High  
> **Created:** 2026-08-17  
> **Owner:** TBD

## Description

Build the project creation flow: name the project, select video/audio/script inputs, and trigger ingest validation.

## Acceptance Criteria

- [ ] "New Project" view with form fields for name, optional description.
- [ ] File selection for video, voiceover, and script (path picker or drag-and-drop).
- [ ] Submit calls `POST /projects` and displays validation feedback.
- [ ] Project list view shows all projects with status badges.
- [ ] Errors from missing/invalid files are shown clearly.

## Dependencies

- WEB-032, WEB-033, PRX-006

## Notes / Scratch

Because the app is local-first, a native file picker returning an absolute path is acceptable on desktop browsers.
