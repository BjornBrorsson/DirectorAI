# WEB-036: Timeline / cut review UI

> **Status:** Done  
> **Phase:** Web Frontend  
> **Priority:** Medium  
> **Created:** 2026-08-17  
> **Owner:** TBD

## Description

Show the generated narrative nodes, visual events, and proposed cuts so the user can review before exporting.

## Acceptance Criteria

- [ ] List or simple timeline view of narrative nodes with thematic tags.
- [ ] Visual events aligned by time.
- [ ] Proposed cuts displayed with source time, timeline time, and track.
- [ ] Approve/reject individual cuts or entire blueprint.
- [ ] Regenerate conform after edits (updates FCPXML without re-running analysis).

## Dependencies

- WEB-035, ASM-020, FCP-022

## Notes / Scratch

A lightweight HTML/CSS timeline is enough for v0.1; full video preview is out of scope initially.
