## Description

Provide a settings page for API key, model selection, FFmpeg path, output directory, and dev/test mode.

## Acceptance Criteria

- [ ] Settings form backed by the existing config module.
- [ ] Masked API key input; server-side storage only.
- [ ] FFmpeg path picker with auto-detect button.
- [ ] Toggle for dev mode (disables live API calls).
- [ ] Validates and saves settings; shows confirmation.

## Dependencies

- WEB-033, FND-004

## Notes / Scratch

Never send the API key to the browser; config is persisted server-side and redacted in UI responses.
